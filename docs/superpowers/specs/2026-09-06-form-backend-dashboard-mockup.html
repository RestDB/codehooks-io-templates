Two roles. The monospace face carries field keys, timestamps, IPs, sizes and IDs — the things that are literally data — with tabular figures so columns line up. That contrast is the character of the page, and it costs zero bytes and zero requests.

The two calls

Teal on warm paper. This is an archive of correspondence from strangers, so the accent reads as archival ink rather than the notification-blue every admin panel uses.

System fonts only. A webfont would mean a Google Fonts request, which is the thing approach A exists to avoid. The lift comes from the palette, the type scale and the record layout instead.

Both are cheap to change — they're four CSS variables and one font stack. Tell me what you'd move.
